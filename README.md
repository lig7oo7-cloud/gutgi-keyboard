# 굿기 키보드

딩굴처럼 굿기(드래그) 방향으로 한글을 입력하는 안드로이드 키보드.

## 설치 (갤럭시)
1. 이 저장소의 **Releases** 에서 최신 `gutgi-keyboard.apk` 다운로드
2. 설치 시 "출처를 알 수 없는 앱" 허용
3. 앱 실행 → ① 키보드 사용 설정 → ② 굿기 키보드로 바꾸기

코드를 main 에 올리면 GitHub Actions 가 자동으로 APK 를 빌드해 Releases 에 올린다.
